# Vision Hook: "Multimodal Detector"

**Objetivo:** Interceptar menciones a elementos visuales (figuras, tablas, gráficos, esquemas) para activar un análisis multimodal preciso.

**Instrucción Obligatoria:**
"Si el usuario menciona una 'Figura', 'Tabla', 'Gráfico' o 'Imagen' del PDF:
1.  **Identifica** el archivo y la página específica mencionada.
2.  **Focaliza:** Utiliza tus capacidades visuales nativas para analizar detalladamente dicho elemento.
3.  **Acción:** Proporciona un 'Image-to-LaTeX' para fórmulas complejas dentro de la imagen o un 'Image-to-Description' técnico para arquitecturas. No te limites a leer el pie de foto; describe el flujo de datos visual."
